      3 · Common fixes
      
    
      
      
      
        Logo blank / broken dikh raha hai
        
        
          
      1. Check karein ki assets/ folder repo me upload hua hai. Chat se sirf single files download karne par ye folder chhoot jaata hai — hamesha soleora.zip extract karke poora folder upload karein.
        2. 
          
      2. GitHub par repo kholein: assets/logo-mark.png click karke dekhein ki image preview aa rahi hai. Na aaye to file upload nahi hui.
        3. 
          
      3. File names case-sensitive hain. Logo-Mark.PNG kaam nahi karega, sirf logo-mark.png.
        4. 
          
      4. Repo root me .nojekyll file honi chahiye, warna GitHub Pages kabhi-kabhi folders skip kar deta hai.
        5. 
          
      5. Purana version cache me ho sakta hai — Ctrl+Shift+R (Mac: Cmd+Shift+R) se hard refresh karein.
        6. 
        
      
      
      
      
      
        Google Sheet me data record nahi ho raha
        
        
          
      1. script.js ke CONFIG.API_URL aur admin.js ke ADMIN.API_URL — dono me web app ka /exec URL paste hona chahiye. Khaali chhodne par site demo mode me chalti hai.
        2. 
          
      2. URL /exec par khatam hona chahiye, /dev par nahi.
        3. 
          
      3. Apps Script me SHEET_ID bhara ho — placeholder text nahi.
        4. 
          
      4. Ek baar setup function Run karke permission approve ki ho (tabs Orders aur Subscribers ban jaayein).
        5. 
          
      5. Deploy karte waqt Who has access: Anyone chuna ho. "Anyone with Google account" se site ke requests block ho jaate hain.
        6. 
          
      6. Code.gs edit karne ke baad Deploy → Manage deployments → Edit (pencil) → Version: New version → Deploy karna zaroori hai. Sirf save karne se live URL update nahi hota.
        7. 
          
      7. Passcode dono jagah same hona chahiye — Code.gs ka ADMIN_KEY aur admin login ka passcode.
        8.
